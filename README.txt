LabSpex website — upload to GoDaddy
===================================
1. In GoDaddy, open your hosting > File Manager (cPanel), go to public_html
   (or use Website Builder? -> this needs regular Web Hosting, not Website Builder).
2. Upload index.html, styles.css, script.js and the whole assets folder, keeping the same structure.
3. Visit your domain. Done.
